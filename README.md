# QA Orbit MVP

A polished Android starter prototype for QA Orbit: Learn + Practice + AI Interview.

## Included
- Home dashboard
- Animated QA Orbit hero card
- Learning roadmap
- Module/lesson flow
- Visual diagram and automation code example
- Practice section
- AI Interview landing page
- Text-based mock interview prototype with feedback
- Material 3 UI
- Dark/light-ready design foundation

## Stack
- Kotlin
- Jetpack Compose
- Material 3
- MVVM/Clean Architecture-ready structure
- Android API 36 target

## Build
Open the project in Android Studio and let Gradle sync/download dependencies, then run the `app` configuration on an emulator or Android device.

This environment does not have the Android SDK/Gradle toolchain installed, so an APK/AAB was not compiled here. The source project is provided for Android Studio build and further development.
